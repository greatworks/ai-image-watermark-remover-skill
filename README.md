# AI 生图自动去水印

> 装一次，之后每个会话都默认生效。AI 出图完自动裁掉右下角水印，不用再跟模型说「把水印去掉」。

## 它解决什么

图像生成工具会在图片右下角压一行半透明角标（`AI生成 / WORKBUDDY`），生成参数里的 `footnote` 关不掉。每张图都要补一句「去水印」，既费口舌又容易漏。

装上这个技能后，生图任务里多了一步默认动作：图片落盘后先裁掉底部水印，再交付。不需要用户开口，不需要额外指令。

## 装完之后会发生什么

1. **首次用到时**，技能会把一条规则写进你的用户级记忆文件（`~/.workbuddy/user-*-personal/MEMORY.md`），内容只有一段被注释标记包裹的说明：AI 生图后自动去水印。
2. 这段规则随每个新会话注入，所以**之后哪怕不触发这个技能，模型也知道该做这件事**。
3. 规则块可一键移除，不会改动记忆文件里的其他内容；首次写入前会自动备份为 `MEMORY.md.wm-backup`。

如果你不希望修改记忆文件，直接告诉模型「不要开启全局规则」即可，技能只对当次任务生效。

## 用法

```bash
# 单张或多张
python <技能目录>/scripts/remove_watermark.py a.png b.jpg --json

# 整个目录
python <技能目录>/scripts/remove_watermark.py --in ./images --json

# 只看会裁多少，不写盘
python <技能目录>/scripts/remove_watermark.py a.png --dry-run

# 只判断是否疑似有水印（启发式，仅供参考）
python <技能目录>/scripts/remove_watermark.py a.png --detect
```

| 参数 | 作用 |
| --- | --- |
| `--ratio 0.08` | 底部裁切比例，默认 0.08，安全区间 0.02~0.25 |
| `--detect` | 只检测，不修改文件 |
| `--dry-run` | 只预览，不写盘 |
| `--keep-original` | 保留一份 `_orig` 副本 |
| `--force` | 忽略已处理标记，强制再裁一次 |
| `--json` | 输出结构化结果 |

## 裁剪比例是怎么定的

实测水印在 `1536×1024` 图上占据纵轴 92.9%~98.0%，在 `1024×1024` 图上约 95.2%~99.7%，随画幅等比缩放。因此固定裁掉底部 8% 可以稳定覆盖，宽度不变，画面比例轻微变化（16:9 → 约 16:9.63），视觉损失可以忽略。

## 幂等

同一张图被处理两次就会裁掉 16%，所以脚本会在图片元数据里写标记：

- PNG → `tEXt` 文本块
- JPEG / WebP → EXIF `UserComment`

重复调用直接返回「已去过水印」，不会二次裁剪。BMP 与 TIFF 无法携带自定义元数据，因此不支持这两种格式，避免被反复裁剪。

## 环境要求

优先使用 Pillow。没有 Pillow 时自动降级：

- Windows → System.Drawing（PowerShell，系统自带）
- macOS → sips（系统自带）
- Linux → 需要先装 Pillow

降级后端不写幂等标记，同一张图请只调用一次。

## 边界

- **只处理 AI 生成的图片**。用户自己上传的照片、截图、设计素材不要用这个技能处理，裁掉 8% 会破坏原始内容。
- 动图（GIF）不支持，BMP / TIFF 不支持。
- 这是裁切，不是像素级修复。水印不在底部、或高度超过 8% 的场景需要手动调 `--ratio`。

## 隐私

脚本只读本地图片、只写本地图片，不联网、不上传、不包含任何统计或回传逻辑。全局规则只写入本机的记忆文件。

```bash
# 只关掉全局自动执行

```
